# Frontend Scaffold

This directory contains a minimal Next.js 15 scaffold for the AI Book Reader UI. The project
uses the App Router and ships with TypeScript, ESLint and a simple landing page.

## Getting started

```bash
cd frontend
npm install
npm run dev
```

The development server listens on [http://localhost:3000](http://localhost:3000). Update the
API URLs in your components when the backend endpoints are available.
